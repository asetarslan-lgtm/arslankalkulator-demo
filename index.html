Pertanyaan umum

Datanya disimpan di mana?

Di browser perangkat Anda sendiri, jadi tidak ada server atau langganan. Sebaiknya unduh cadangan secara berkala, karena data bisa hilang bila data browser dihapus.

Perlu internet?

Tidak untuk menghitung. Internet hanya dipakai saat membuka dan mengunduh filenya.

Bisa dipakai untuk usaha selain makanan?

Bisa. Bahan, biaya, dan saluran penjualannya Anda isi sendiri, jadi rumusnya berlaku untuk usaha dagang dan produksi apa pun.
